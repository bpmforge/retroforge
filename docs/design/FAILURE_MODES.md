# Design: Failure Modes (R-F1, design-review arc P4)

Every moving part, its failure, and the designed response. Rule: **no
failure aborts emulation silently, no failure is invisible in the UI, and
every row names its test.** Rows append as field reports arrive (each
incident also gets a LESSONS.md row).

| # | Failure | Detection | Containment | User-visible state | Recovery | Test |
|---|---|---|---|---|---|---|
| FM-01 | Core panic mid-frame (emulation bug) | catch_unwind at the core-thread boundary | Core thread halts; host/UI threads unaffected | Error dialog with ROM hash + trace-ring tail; offer state save of last frame boundary | Reload ROM / load last state; auto-save crash report locally | UT: injected panic in mock core |
| FM-02 | Audio underrun cascade (slow host, buffer drain) | Ring fill-level watermark in cpal callback | Rate control widens toward +0.5%; below hard floor, emit silence — never block the callback | Buffer-health dot goes amber/red (FRONTEND_UI status bar); diagnostic counter (FR-FE-006) | Self-heals via rate control; persistent = suggest larger buffer in Audio settings | Soak test W2-05; forced-starvation UT |
| FM-03 | GPU device loss / shader-compile failure | wgpu error scopes + surface error on present | Fall back to original pipeline (FR-REND-007); emulation never pauses | Toast "renderer degraded"; Enhance features grey out | Recreate device; re-enable enhanced pipeline on success | Simulated device-loss test (W3-01) |
| FM-04 | Cache corruption (bad hash on rf-cache entry) | Content-address verify on read | Entry dropped + rebuilt from source data; never crash, never serve bad data | Momentary fog/original assets while rebuild runs | Automatic (cache is derived data by construction) | UT: bit-flipped cache entry (W4-08) |
| FM-05 | Profile decode error mid-play (bad rules/ROM revision drift) | Decoder returns Result; validator at load | Feature that needed the decode degrades to generic tier (stitcher); profile marked errored | Profile chip turns amber; inspector shows offending rule + offset | Fix profile (hot-reload, W5-06); revision override | UT: fuzzed decode rules (W5-02a) |
| FM-06 | Plugin/script fault storm (error every frame) | Per-callback catch + error counter | Script auto-paused after N faults (FR-PLUG-004); native plugin disabled for session | Toast + plugin list shows error state + last message | User re-enables after fix | Plugin containment test (TESTING §7) |
| FM-07 | Plugin over budget (frame pacing at risk) | Host measures callback time per frame | Throttled to every-N-frames (FR-PLUG-005) | Budget meter in plugin list | Self-heals; user can raise budget | UT: busy-loop plugin |
| FM-08 | Replay divergence (determinism bug) | Periodic state-hash mismatch vs .rfreplay | Replay halts at first divergent frame | Divergence report: frame N, both hashes | Harness dumps replay slice + hashes as CI artifacts (W4-01, R-F4); bisect via hash checkpoints | Determinism suite (TESTING §6) |
| FM-09 | Save-state migration failure (old chunk version, no migration fn) | Chunk version check on load | Load refused whole — never a half-loaded machine | Error names the chunk + versions ("PPU_ v2→v4: cannot migrate") | Golden fixtures per release catch it in CI first (FR-STATE-005; drill R-F3) | Fixture-load suite |
| FM-10 | Wrong-ROM state load | Normalized-hash mismatch in header | Refused (FR-STATE-003) | Diagnostic names both hashes/titles | Pick matching ROM | UT (W2-04) |
| FM-11 | Stitcher canvas explosion (false scene cuts, R-17) | Canvas count per scene watermark | New canvases keep working (worst case = fragmentation, never corruption) | Report card row (D-004): scene-cut resets counted | Per-game threshold override in profile; canvases mergeable offline later | Stitcher determinism + fixture with palette flashes (red fixture) |
| FM-12 | De-flicker shows intentionally hidden sprite (R-03) | Blink-period check + user report | Safety auto-re-enable fires; event recorded | Badge pulse + report card row; suppression needs justification (FR-ENH-012) | Profile exclusion (`[antiflicker]`) | Intentional-blink red fixture (FR-ENH-013) |
| FM-13 | OOM risk on huge enhanced render targets (ultrawide/full-map) | Allocation-size guard vs adapter limits before target creation | Camera falls back to smaller target/zoom level; never device-lost by our own alloc | Toast "view too large for GPU, reduced" | Pick smaller mode; cap in Video settings | UT: mocked adapter limits |
| FM-14 | Test-ROM source rot (R-09: URL 404s) | fetch-test-roms.sh hash/download failure | CI job fails loudly naming the artifact; cached copies keep local runs alive | n/a (CI) | Switch to mirror URL in manifest; multiple mirrors pre-listed | Manifest verify step |
| FM-15 | Path escape attempt (symlinked library dir, malicious profile path, plugin cache escape) | realpath containment check (D-006) | Access refused with diagnostic naming the offending path | Toast/log line; plugin gets an error, not a silent empty read | Remove symlink or widen roots deliberately | Containment UT per surface (NFR-010) |
