# W34 screenshots: HD-2D and Diorama

Made by `crates/retroforge/tests/w30_screens.rs` (`RF_SCREENS_ONLY=<filter>`:
`w34-tour-alttp`, `w34-tour-smb3`, `w34-tour-wide` (SMW 32:9 then 4:3),
`w34-tour-sheet`, plus the earlier `diorama-*` and `hd2d-full` shots), real
games from `~/Games/Roms`, release build, cold cache for first visits. Frames
with the player dead or a fade on screen were rejected: the SMB3
`diorama-side-*` / `diorama-layers-*`, the SMW `diorama-layers-*` and
`diorama-light-smw-*` sets were removed and the tour set replaces them. The HD-2D
preset is the one-click card (grade on by default). Each file under 1.5 MB.
