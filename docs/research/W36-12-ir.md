# W36-12: semantic IR, IR interpreter, Rust emitter, and the JIT ceiling

Measured 2026-10-26 on an Apple M2 Max, release builds, **on a loaded shared
machine** (load average 3.1 to 4.9 while other sessions built and tested). Read
the ratios; the absolute milliseconds drift by a few percent run to run (two
runs of the Amdahl bench are noted where they differ).

## Result in one paragraph

The expected result held: **there is no speed gain to be had from a faster way
to execute 6502 instructions on this core**. The NES core ticks the PPU and
APU on every bus cycle, a tier that must issue the same cycle stream can only
remove opcode decode, dispatch and ALU work, and that work is **5.7% to 6.5%
of a frame**. An executor with infinitely fast CPU code would speed a frame up
by 1.06x to 1.07x. The IR tier built here is correct (vectors, nestest, SMB
lockstep) and is **slower** than the hand-written interpreter (+13% a frame on
SMB), because it spends the same bus calls plus an op loop. The IR is still
the right artefact for the Rust emitter and for any future compiled tier; the
speed, if it is ever wanted, comes from a scheduling change (CPU-only runs
between hardware accesses), not from code generation.

## 4. The IR

`rf_rebuild::ir` (ISA-neutral): `Val` (immediate, register, temp, flag),
`Op`:

- `Read { dst, addr, kind }`, `Write { addr, val, kind }`: one bus cycle each,
  `Cycle` = Fetch, Pointer, Data, Stack, Vector, Probe (read at a possibly
  uncorrected address), Dummy (value discarded, still a cycle: unindexed
  probes, implied-mode re-reads, RMW write-back of the old value).
- `Set`, `Alu { op, w, a, b }` (Add, Sub, And, Or, Xor, Not, Shl, Shr, Eq, Ne,
  Ge, Gt, Sext8, Join; `Width` W8/W16), `SetFlag { flag, src }`: flags are
  computed from ALU ops (ADC's carry is bit 8 of a 16-bit sum, V from the xor
  identity, N and Z from `And` and `Eq`); there is no "set NZ" shorthand.
- `SkipUnless { cond, n }`: forward-only; page-cross re-reads, taken-branch
  cycles. A program ends in at most `ops.len()` steps; `validate()` checks
  temps are written before use on every path and skips stay in range.
- `Machine(..)`: `BranchPollsEarly` (taken, no page cross), `PollMaskFromFlags`
  (RTI, interrupt entry), `InterruptEntry`, `SelectVector` (NMI hijack).

`Lowering::Interpret` marks what is not lowered: the twelve `JAM` opcodes and
the unstable ones (`ANE`, `LXA`, `LAS`, `SHA` x2, `SHX`, `SHY`, `TAS`): 20
opcodes. The other 236 lower (`BRK` among them), and so do the hardware NMI
and IRQ entries. `lower_opcode` gives the generic program (operand
bytes come off the bus, so a bank switch under the instruction is seen);
`lower_insn`/`lower_block`/`lower_function` lower a located atlas instruction
with its bytes baked in by `ir::bake` (constants folded, fetch cycles kept),
which is what the emitter prints.

## 5. Oracles (all run, release)

- SingleStepTests nes6502, IR tier: 256 opcodes, 2,560,000 cases, trace and
  state: 2,555,578 pass, 4,422 fail, all `$AB` (LXA, the documented
  convention clash the interpreter fails identically: 1,045,578 + 4,422 on
  the 105 unofficial opcodes, 1,510,000 of 1,510,000 official). 2,360,000
  cases ran lowered IR, 200,000 ran the interpreter's own arm (the 20
  `Interpret` opcodes).
- nestest golden log, IR tier: 8991 of 8991 lines.
- `RF_NES_TEST_TIER=ir cargo test -p rf-nes --lib`: all 417 unit tests with
  every `Cpu` on the IR tier (interrupt timing, system and mapper tests).
- SMB lockstep (`RF_W36_TIER=ir`, `w36_04_lockstep_smb`): 1-1 by real play
  and all 32 levels x 2 scripts, 108,800 frames compared, 1,044,410,226
  instructions, **zero divergence**; plain core on the interpreter, rebuilt
  core on atlas + IR tier.

## 6. Rust emitter

`rf-nes/src/rebuild/emit.rs`: one `pub fn f_XXXX<B: Bus>(r: &mut Regs, bus:
&mut B)` per atlas function, a `match r.pc` arm per instruction, comments
naming each cycle, DUMMY marked. It does not model interrupt polling and
returns when `pc` leaves the function or reaches an `Interpret` instruction.
Ignored test `tests/w36_12_emit.rs`: RF-Scroller, 56 functions, 43,405 lines,
compiled with `rustc --crate-type lib --edition 2021` into `target/`. Output
for a commercial game is not committed and the test does not produce any.

## 7. What this does and does not support

- A native-code tier on this core buys at most the 6% above, and the measured
  IR evaluator shows the dispatch it would replace is not where the cost is.
  W36-12b should not start with Cranelift; it should start with the scheduling
  question in REBUILD_LAB section 4 (run the CPU without ticking devices until
  a hardware access), which the lockstep checker can now test.
- The IR is the shared description the emitter, a future compiled tier and
  tier-3 replacement functions can all read.
- Not done: running the emitted Rust against a bus (compile only), baked
  forms inside the evaluator (it takes operands off the bus), SNES lowering.
