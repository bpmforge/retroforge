# Game info

**Quick Menu › Game info** lists everything this game's profile knows how
to read: lives, health, coins, rupees, bombs, missiles, stage, power-up and
so on, with their values right now. Items marked **checked in play** were
seen behaving correctly on this copy of the game; the rest come from a
community map and have not been checked yet.

![Game info in the Quick Menu](tour/44-game-info-menu.png)

Tick an item to pin it. Pinned items show as small chips over the game, up
to four, in the corner you choose under **Where it shows**. Pins are saved
for each game.

![Pinned items over the game](tour/45-game-info-chips.png)

Reading these values never changes the game, so Game info works in every
mode, Original included. Values read the way the game shows them where the
profile says how: lives shown from 1 rather than 0, a power-up by name, a
timer as digits.
