# RetroForge — Architecture Decision Records

Design-review arc P4 (2026-07-15). Condensed ADRs for every load-bearing
choice; each carries a **Rejected:** line. Deep rationale lives in the cited
docs — these rows are the decision spine. New ADRs append.

| # | Decision | Why | Rejected |
|---|---|---|---|
| ADR-1 | **Rust workspace, 16 crates**, MIT OR Apache-2.0 | Memory safety for a long-lived codebase; crate boundaries carry the layer law (validate-arch.sh); one toolchain core→UI→WASM-later (TECH_STACK §1) | **Rejected:** C++ (no boundary enforcement, GPL reference-emulator contamination risk); monolith crate (boundaries become convention, not law) |
| ADR-2 | **wgpu 30** as the only GPU abstraction | One API → Vulkan/Metal/DX12/GL/WebGPU; egui shares the device; headless golden frames (rust-stack §1) | **Rejected:** raw Vulkan+Metal+DX12 (3× platform code for a 2D scanout workload); OpenGL-only (dying on macOS) |
| ADR-3 | **egui/eframe + egui_dock** immediate-mode UI | Per-frame debug panels re-render from live core state with no sync layer; proven by TetaNES/Mesen-shape tools (rust-stack §2) | **Rejected:** Tauri (IPC hop wrong for 60fps memory viewers); iced/Slint (wrong shape for dockable per-frame debug UIs) |
| ADR-4 | **Indexed pixels + metadata across the core boundary** (never RGB) | The single decision enabling layer extraction, de-flicker, HUD split, palette-aware packs without RGB heuristics (ARCH §5) | **Rejected:** RGB framebuffer out (every enhancement becomes image processing); per-feature core hooks (couples cores to features) |
| ADR-5 | **Mesen-style cycle/scanline state-machine cores**, catch-up scheduled | Hook-friendly, cheap savestates, deterministic stepping (EMULATION_CORES §1) | **Rejected:** ares-style cooperative threads (gold-standard accuracy but resists hooks, savestates need stack unwinding — prior-art §3) |
| ADR-6 | **Single core thread; enhancement observes via FrameBundle + StateView** | Determinism invariant is structural: workers can lag, never write back (ARCH §6) | **Rejected:** parallel chip emulation (timing nondeterminism); enhancement calling into a running core (data races, perturbation) |
| ADR-7 | **bincode 3 payloads inside a hand-rolled versioned TLV container** | Fastest codec, swappable because the container is ours; per-crate chunk ownership (SAVE_STATES §2) | **Rejected:** raw serde JSON (size/speed); savefile/versionize (dependency owns our format); postcard (adopt only if wire-stability outranks speed) |
| ADR-8 | **Profiles are TOML data, never code**; plugins carry code | Shareable, diffable, clean-room-auditable per-game knowledge (GAME_PROFILES §1) | **Rejected:** per-game Rust modules (NON_GOALS #16 — unmaintainable, unshareable); embedded scripts in profiles (blurs the capability boundary) |
| ADR-9 | **Lua (mlua) first; WASM (wasmtime) only at Phase 9** | Lua is the emulator community's lingua franca (BizHawk/Mesen); WASM before API stability freezes a bad ABI (PLUGINS §1) | **Rejected:** WASM-first (novel, no community, per-frame boundary copies); native plugin ABI now (churn lock-in, R-06) |
| ADR-10 | **Audio-clock-driven pacing + dynamic rate control (rubato ±0.5%)** | The libretro-proven solution to the 60.0988 Hz vs display clock mismatch (RENDERER §8, rust-stack §3) | **Rejected:** vsync-driven emulation speed (audio pitch drifts); free-running + naive resample (underruns/crackle, R-15) |
| ADR-11 | **Accuracy defined by test-ROM gates, not by matching another emulator** | Objective, automatable, citable (TESTING; NON_GOALS #7) | **Rejected:** ares-parity as the bar (unbounded); "plays my games" (unfalsifiable) |
| ADR-12 | **Self-contained game fixtures (D-001)**: RF-Scroller/-S in-repo; oracles stay external | License risk designed out; fixtures double as red-fixture hosts | **Rejected:** third-party homebrew as gate fixtures (Nova lesson — assets were NC/all-rights-reserved); rewriting accuracy oracles (weakens the claims they ground) |
| ADR-13 | **Heuristic trust ladder (D-004)**: shadow→advisory→active + local report card | Honesty contract made mechanical; FP economics without telemetry (NFR-005) | **Rejected:** global toggles that silently break games (Mesen #60/#188); cloud telemetry FP measurement (violates NFR-005) |
| ADR-14 | **Deny-by-default license-gated intake (D-005)** | The review found NC/GFDL/GPL content one hop from the repo; intake is where taint stops | **Rejected:** trust-the-contributor (how shader/asset taint happens); manual-only review (doesn't scale to an ecosystem) |
| ADR-15 | **Path containment law (D-006)**: realpath + root confinement everywhere | Closes the symlink/traversal class before any path code exists | **Rejected:** per-surface ad-hoc checks (the class recurs); full sandboxing now (wasmtime tier is the Phase-9 answer) |
| ADR-16 | **Board executes WIP=1** (one ticket/session, one conductor — D-003); P8 territory law scoped to concurrent-active overlap | Solo-maintainer + agent model; parallel write-races designed out rather than managed | **Rejected:** parallel executor fleet now (halved throughput at Shipwright, L-21; overlap matrix says 247 todo pairs would need lanes first) |
