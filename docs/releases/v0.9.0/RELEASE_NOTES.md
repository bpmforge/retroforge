# RetroForge v0.9.0

Commit `2c4f2627bfb9441faaf10ebce78937a970526055`

## What's new since v0.1.0

The first release since August: about 760 commits. The highlights:

**Playing**
- A redesigned app: a game library with cover art, filters, favourites and
  "Continue"; a Quick Menu on Esc (save states with pictures, rewind,
  display, enhancements, Game info, controls, settings) that works from
  keyboard and controller; searchable Settings.
- The SNES core plays the commercial mainstream: on a local No-Intro
  library it renders 1233 of 1265 SNES and 1234 of 1281 NES archives.
- Controls for keyboard and controller on both consoles, with defaults that
  work out of the box and click-then-press rebinding on a drawn pad.
- Ten save-state slots per game, rewind (hold Backspace), fast-forward,
  screenshots and video recording.
- The picture fits the game exactly, with shaders (CRT and more), an
  ambient glow and bezels.

**Enhancements** (opt-in; Original mode is always exactly what the console
drew)
- Three modes per game: Original, Enhanced (no sprite dropout, steady
  sprites) and Game-Aware (widescreen, whole-level maps, skip loading, fog,
  3D dioramas and Mode 7 in 3D, from the game's profile).

**Game profiles**
- About 65 commercial games have profiles, including the Mario, Zelda,
  Metroid, Contra, Castlevania and Mega Man series. Each camera was found
  by playing that dump; about 350 item addresses (lives, health, coins,
  rupees, missiles…) are cited from community RAM maps, most of them
  checked in play.
- No profile? RetroForge finds the camera while you play and offers to save
  it, or the profile builder walks you through finding addresses.
- Game info: pin lives, health and more as chips over the game.

**Documentation**: a player guide and a screenshot tour in `docs/site`.

**Platforms**: macOS only. There are no machines to build and test Windows
or Linux on, so no artifact is published for them.

## Install (macOS, Apple silicon)

Download `retroforge-v0.9.0-aarch64-apple-darwin.zip`, unzip it, and run
`retroforge` from the unzipped folder; keep the `profiles` folder next to
it, which is where the app finds its game profiles. The build is not
signed, so macOS may refuse it the first time: allow it under System
Settings › Privacy & Security, or run
`xattr -d com.apple.quarantine retroforge` in that folder. Then see the
[player guide](https://github.com/bpmforge/retroforge/blob/v0.9.0/docs/site/src/getting-started.md).

## Artifacts

Built and runnable here: `aarch64-apple-darwin`.

**Not produced, and why.** The macOS/Windows/Linux matrix needs machines this project does not have. GitHub Actions is out of budget permanently (ruling 2026-08-22) and cross-building Windows and Linux from the darwin dev machine is not a substitute: wgpu makes it awkward, and an artifact nobody has RUN on the target OS is not evidence of a release. A self-hosted runner or Gitea Actions would restore it; both are free and neither is set up.
