# RetroForge v0.9.1

Commit `caf43a3ca2a48824693056712b5e76dd37bdb3cf`

## What's new in 0.9.1

- **Windows and Linux builds.** Each release now ships three downloads:
  macOS (Apple silicon), Windows (64-bit) and Linux (x86-64), each with the
  game profiles. They are built by GitHub Actions from the tagged commit.
  The Windows and Linux builds are compiled there but have not yet been run
  on real hardware by the project, so treat them as untested and report
  anything that goes wrong.
- **Choose the graphics backend: Vulkan, DirectX 12, Metal or OpenGL.**
  Settings › Video › Graphics, with Auto (the best one for your computer)
  by default. It shows which backend and GPU are running. A choice that
  cannot start on your machine falls back to Auto.

## Install

Download the archive for your computer, unpack it and run `retroforge`
(`retroforge.exe` on Windows), keeping the `profiles` folder next to it.
The builds are not signed: on macOS allow the app once under System
Settings › Privacy & Security; on Windows choose "More info", then "Run
anyway". Linux needs a Vulkan or OpenGL driver and ALSA for sound. See the
[player guide](https://github.com/bpmforge/retroforge/blob/v0.9.1/docs/site/src/getting-started.md).
